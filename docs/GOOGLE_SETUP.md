# Google 連携の準備手順（Google Cloud）

添付ファイル（Google ドライブ）を使うための設定です。予定の表示・作成・変更・削除はスマホの Google の同期機能が行うので、ここでの設定はいりません。
作業はオーナーの Google アカウントで 1 回だけ行います。

このアプリが使う権限は `drive.file`（このアプリが作ったファイルだけ）の 1 つだけです。Google の審査は不要です。

## 1. プロジェクトを作る
1. https://console.cloud.google.com/ を開く
2. 画面上部のプロジェクト選択 →「新しいプロジェクト」→ 名前は任意 →「作成」

## 2. API を有効にする
「API とサービス」→「ライブラリ」で **Google Drive API** を検索して「有効にする」。

## 3. 同意画面を設定する（Google Auth Platform）
1. **アプリ情報**：アプリ名 `Calendar`、ユーザーサポートメールに自分のアドレス
2. **対象**：「外部」
3. **連絡先情報**：自分のアドレス →「作成」
4. **データアクセス**：スコープは `.../auth/drive.file` だけにする（ほかは入れない）
5. **対象** →「公開ステータス」→「アプリを公開」で**本番環境**にする（「テスト」のままだと 7 日ごとにログインし直しになる）

## 4. Android 用のクライアントを作る
「クライアント」→「クライアントを作成」で次のとおり作る。

| 項目 | 値 |
|------|----|
| アプリケーションの種類 | Android |
| パッケージ名 | `io.github.barista9409.calendar` |
| SHA-1 証明書フィンガープリント | `6E:BE:34:11:1C:55:FD:2E:82:EB:A2:0A:D6:C6:11:64:07:77:1F:00` |

- SHA-1 はリリース用署名鍵のもので、秘密情報ではない
- クライアント ID をアプリに組み込む必要はない（パッケージ名と SHA-1 で照合される）
