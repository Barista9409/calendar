# Google 連携の準備手順（Google Cloud）

アプリから Google カレンダー（共有設定・色・カレンダー管理）と Google ドライブ（添付ファイル）を使うための設定です。
作業はオーナーの Google アカウントで 1 回だけ行います。所要時間は 15 分ほどです。

## 1. プロジェクトを作る
1. https://console.cloud.google.com/ を開く
2. 画面上部のプロジェクト選択 →「新しいプロジェクト」
3. プロジェクト名：`Calendar App`（任意）→「作成」

## 2. API を有効にする
「API とサービス」→「ライブラリ」で次の 2 つを検索し、それぞれ「有効にする」を押す。
- **Google Calendar API**
- **Google Drive API**

## 3. 同意画面を設定する（Google Auth Platform）
「API とサービス」→「OAuth 同意画面」（または「Google Auth Platform」）を開き、「開始」を押す。

1. **アプリ情報**：アプリ名 `Calendar`、ユーザーサポートメールに自分のアドレスを入力
2. **対象**：「外部」を選択
3. **連絡先情報**：自分のアドレスを入力 → 同意して「作成」

続けて左メニューの各画面で設定する。
- **データアクセス** →「スコープを追加または削除」で次の 3 つにチェックを入れて「更新」→「保存」
  - `.../auth/calendar`（Google カレンダーの表示・編集・共有）
  - `.../auth/drive.file`（このアプリが作成したドライブのファイル）
  - `.../auth/drive.readonly`（共有されたドライブのファイルの閲覧）
- **対象** →「公開ステータス」の「アプリを公開」→「確認」で**本番環境**にする
  - 「テスト」のままだと、7 日ごとにログインし直す必要がある
  - Google の審査（確認）は申請しなくてよい。家族で使う分には、ログイン時に「Google はこのアプリを確認していません」と出るだけ（「詳細」→「Calendar（安全ではないページ）に移動」で進める）

## 4. Android 用のクライアントを作る
「クライアント」（または「認証情報」→「認証情報を作成」→「OAuth クライアント ID」）で次のとおり作成する。

| 項目 | 値 |
|------|----|
| アプリケーションの種類 | Android |
| 名前 | `Calendar Android`（任意） |
| パッケージ名 | `io.github.barista9409.calendar` |
| SHA-1 証明書フィンガープリント | `6E:BE:34:11:1C:55:FD:2E:82:EB:A2:0A:D6:C6:11:64:07:77:1F:00` |

- SHA-1 はリリース用署名鍵のもので、秘密情報ではない
- 「カスタム URI スキーム」などの追加設定は不要
- 作成後に表示されるクライアント ID をアプリに組み込む必要はない（Android ではパッケージ名と SHA-1 で照合される）

## 5. 完了の連絡
上記が終わったら知らせてください。次のアプリ更新で「Google と連携」ボタンが使えるようになります。
家族の端末でも同じアプリ（同じ署名）を使う限り、追加の設定は不要です。
